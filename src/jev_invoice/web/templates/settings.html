Accounting policies

Northwind Analytics policies. The approval limit can be changed below.

  • Subscription costs: Finance reviews subscriptions spanning multiple months for allocation across their service period.
  • Equipment purchases: {% if accounting_policy.asset_threshold is not none %}Potential equipment assets costing {{ currency }} {{ accounting_policy.asset_threshold | money }} or more per item need capitalization review.{% else %}No equipment price threshold is configured.{% endif %} Finance confirms eligibility and useful life.
  • Goods invoices: Orders marked Needs receiving are checked against both the PO and recorded deliveries. Services use the PO only.
  • Approval: Invoices above {{ currency }} {{ approval_limit | money }} require budget-owner approval. Automatic approval requires every control to pass.

Invoice dates stay unchanged. A posting period is proposed from the invoice date; Finance can record a different posting period with an explanation.

Existing pending invoices use the updated policy when rechecked. These controls propose treatment; they do not create depreciation or amortization entries.
